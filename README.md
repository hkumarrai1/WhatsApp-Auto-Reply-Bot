# WhatsApp-Auto-Reply-Bot
AI-powered WhatsApp auto-reply bot using Selenium &amp; SambaNova API. Automatically detects incoming messages, generates intelligent responses via Meta-Llama-3.1-8B, and sends replies. Features persistent login, real-time monitoring, error handling, and secure API key management. Perfect learning project for web automation &amp; AI integration.

AI-powered WhatsApp auto-reply bot using Selenium and SambaNova API.

## Features
- Detects new incoming messages
- Generates AI-powered responses
- Automatic message sending
- Persistent login

## Setup
1. `pip install selenium webdriver-manager python-dotenv requests`
2. Create `.env` file with your API key
3. Run `python main.py`
